# Changelog

## Unreleased

- **More ways to write "ignore previous instructions" are caught:** the attack phrase check now alarms on "Ignore the previous instructions", "Ignore your previous instructions", "Ignore all of the above instructions", "Disregard your prior instructions" and "Forget all previous instructions", while ordinary sentences such as "Ignore previous versions of this file" and "Follow the previous instructions in chapter 2" stay calm. The plugin's `catalog.js` copy is in step. Thanks to @17302513901yh-lang! (#20, #81)
- **`check-text` and `check-file` name the kinds of key they found:** the `file.secret` finding now says `Keys or passwords (2) are written in this text: Anthropic, Mistral. They are not shown.` and has a `kinds` array for programs, in the CLI, the JSON, the MCP tools and the HTTP API. The kinds come only from AgathOS's own list of key patterns; no key, masked or not, is in the answer. Thanks to @17302513901yh-lang! (#56, #70)
- **A mistyped option and a second file are no longer silently dropped on the command line:** `--jsno`, `--standlone` and `-json` now end with exit code 3 and `Unknown option: ...` plus the help, instead of becoming a file name or being ignored; `check-file a.txt b.txt` / `check-text a.txt b.txt` say that the command takes one file instead of checking only the first. A lone `-` still reads stdin, `report` still takes the whole line as its sentence, `check-action` still takes a JSON input that starts with `-` (such as `-1`), and `--json` / `--standalone` work in any position. The plugin's `cli.js` copy is in step. Thanks to @17302513901yh-lang! (#54, #66)
- **`check-action` no longer answers `allow` for input it could not read:** valid JSON that is not an object (`'"rm -rf ~"'`, `'[1]'`, `42`) is refused with exit code 3 and a message that shows the form, instead of being checked as an empty command. A shell tool (`Bash`, `PowerShell`) with no command to look at is exit code 3 too, because nothing was checked. Tools that need no input, such as `WebFetch`, still get their answer. (#53)
- **A long file no longer looks calm when only its start was checked:** `check-file` and `check-text` now say how many characters or MB were actually scanned, in the plain output, the JSON and the MCP tools, and a cut answer is `watch` instead of `calm` — a clean prefix is not a clean file. Short files are unchanged. Thanks to @17302513901yh-lang! (#29, #52)
- **Provider keys stored under a quoted name are found:** `"MISTRAL_API_KEY": "..."` and the single-quote form in `mcp.json` / `claude_desktop_config.json` `env` blocks now give one `Mistral` finding, like the `.env`, YAML and TOML forms. The Gatekeeper also passes `NAME=value` pairs to the secret scan, so a named key with no recognisable prefix is caught in an MCP config too. Placeholders and short values are still skipped. Thanks to @17302513901yh-lang! (#55, #63)
- **An MCP server running from a temp or download folder is noticed on a Mac too:** the `mcp.oddPath` check now accepts both kinds of path separator and knows `/tmp`, `/var/folders` and `/private/var/folders`, so `/Users/me/Downloads/x/server.sh`, `node /tmp/x/index.js` and `C:/Users/me/Downloads/x.exe` are flagged while an ordinary folder such as `/projects/tmpl` is not. Thanks to @17302513901yh-lang! (#17, #50)
- **UTF-16 text files are read, not called binary:** a file saved as UTF-16 with a byte order mark (what PowerShell 5.1 writes with `>`) is now decoded before it is checked, by `check-file` and by `check-text FILE`, so an instruction hidden in it is found. A UTF-32 file or a file full of zero bytes stays `unknown` (binary, not read). Thanks to @17302513901yh-lang! (#30, #40)
- **Look-alike addresses for five more providers are caught:** SambaNova, Novita, DeepInfra, SiliconFlow and MiniMax are now in the brand list the homoglyph and typo checks watch, so `samban0va.ai` and friends are `lookalike` instead of merely `unknown`. Thanks to @17302513901yh-lang! (#34, #46)
- **Names eight more key formats** in scans: SendGrid, DigitalOcean, Databricks, PyPI, Slack webhook, Tavily, Supabase and Pinecone keys. Thanks to @tnalbant! (#33, #39)
- **A download is refused only when a program runs it.** `curl ... | sha256sum`, `| shasum` and `| node-jq` are no longer refused as "runs downloaded code", and `| sudo bash`, `bash <(curl ...)`, `eval "$(curl ...)"`, `| zsh`, `| ruby` and `tee f | sh` now are. Thanks to @tnalbant! (#31, #32, #43)
- **Writes inside or outside the project are decided by path, not by text:** `src/a.js` and `./src/a.js` are an ordinary `WRITE_FILE`, while `/home/me/proj2/…`, `proj/../other/…` and `C:\Users\me\proj2\…` are `WRITE_OUTSIDE`. `\` and `/`, drive letters and `..` are read the same way on Windows, macOS and Linux, and a path that starts with `~`, `$HOME` or `%USERPROFILE%` stays `WRITE_OUTSIDE`. The plugin's `classify.js` copy is in step. Thanks to @17302513901yh-lang! (#61, #69)
- **`check-action` recognises curl and wget upload options:** `curl -d@.env`, `curl -T file`, `curl --data-binary @file`, `wget --post-file=...` and the other upload spellings are now `EXFIL` and denied, where they were `NET_FETCH` and allowed. Downloads that use flags such as `-f` (`--fail`) or `-D` (`--dump-header`) are no longer refused as uploads. Thanks to @17302513901yh-lang! (#57, #73)
- **Edits to the settings and instruction files of other AI programs now get an `ask`:** `check-action` with a write tool answered `allow` for `~/.claude.json`, Windsurf's and Antigravity's `mcp_config.json`, `GEMINI.md`, `QWEN.md`, `.windsurfrules`, `.clinerules`, `.github/copilot-instructions.md` and `SKILL.md`. They are now `MCP_CONFIG_CHANGE` and the answer is `ask`. The names come from the catalog (`MCP_CONFIGS` and `INSTRUCTION_FILES`), and a generic `config.json`, `settings.json` or `mcp.json` only counts inside the folder the catalog names for that app, so a bare `/project/config.json` is still an ordinary write. The plugin's `classify.js` copy is in step. Thanks to @17302513901yh-lang! (#13, #72)

## 0.13.1 — the good guardian

- **The good guardian:** the new tagline and welcome text, in all 20 languages. The word "daemon" is gone from the app, the README and the website.
- **A window sent to the tray stays there**, and its release no longer depends on the system's hide event.
- **A Claude Code OAuth token is named as an Anthropic key.** A `claude setup-token` value was reported as "OpenAI / DeepSeek", which sent people to the wrong provider to revoke it (#22).
- **MCP servers in a project's `.gemini/settings.json` and `.qwen/settings.json` reach the Gatekeeper**, and risky settings in those files are still reported (#27).
- **The command line is packaged for npm** as `agathos-os` (the command stays `agathos`).
- **Website, `llms.txt`, CONTRIBUTING and issue forms** so people, search engines and AI assistants can find and describe AgathOS, and newcomers know how to help.
- **Updated dependencies:** Electron 45 and the GitHub Actions used by the builds.
